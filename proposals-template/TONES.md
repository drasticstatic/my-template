# 🎨 Tones: one colour family per organisation, four shades each

Every proposal in the fleet wears the same shape (TL;DR first, icons beside ideas, a decisions log, a PDF for human
eyes) so a reader learns it once. The **tone** is what tells them *whose* it is before they read a word: the badge
colours in the header, the icon strokes, and the heading colours in the PDF. One family per organisation; nothing
else changes. Each family is **four shades**, so a page carries a gradient of one hue rather than a wash of it.

## Which look for which repo

**Ask whom the repository serves.** If it belongs only to drasticstatic and serves no organisation, it wears **maroon on navy with Phosphor duotone** icons, so it stands out as his. If it is a lab desk drafting for an organisation, it wears **brass on slate with Lucide** and takes that organisation's accent, so the lab is the author and the hue says who it is for. If it belongs to an organisation, it wears **that organisation's family with Lucide**, and nothing of the lab's.

Christopher decided this on Nov 5, 2026. A banner for any of them: `python3 scripts/make-banner.py --family maroon` (short names `drasticstatic`, `ds`), `--family brass`, or the organisation's family. Icons for a maroon repository: `python3 scripts/to-phosphor.py assets/icons`, which keeps every filename, so no README link changes ([`../LUCID.md`](../LUCID.md)).

## Where each shade goes

| Shade | Badges | Icons | PDF |
|---|---|---|---|
| **Primary** | the proposal number | every stroke (`retone-icons.sh`) | the rule under each H2, horizontal rules, links (unless an accent is set) |
| **Deep** | status | | H1 and H2 text, table-head text |
| **Mid** | date | the darker fill on the status icons | H3 and H4, `<details>` summaries, footnotes |
| **Tint** | | | the wash behind block quotes and table heads |
| **Accent** (lab desks, and maroon) | | | links and the quote bar. A lab desk takes the *served* organisation's primary: `TONE_ACCENT=5b2bb5` for a `pir-devine-news` proposal, `d97706` for one that serves THEF; headings stay brass on slate, so the lab is still the author and the hue says who it is for. Maroon's accent is always navy: `TONE_ACCENT=0f3460` |

Body text stays black on white: the tone is a frame, not a wash.

## Icons

**Phosphor duotone, for drasticstatic's own.** `python3 scripts/to-phosphor.py assets/icons` overwrites each mapped icon with the two-tone art in `800020`, same filename, leaving `status-*` alone. The master set is [`../assets/icons-phosphor/`](../assets/icons-phosphor/). Each icon also carries one small `<style>` that lifts it to `e07a8f` in a dark colour scheme, because `800020` on GitHub's dark ground is 1.75:1 and `e07a8f` is 6.62:1; the browser honours it inside `<img>`, following the page's own theme, so a README needs no second file. Shields badges draw their own background, so a maroon badge stays maroon.

**Lucide, for everyone else.** The icon set ships amber. Once per repo: `sh proposals/scripts/retone-icons.sh PRIMARY MID` rewrites the strokes
and the darker fill, leaving the semantic colours alone. (Taylor'd and Ethereal Offering were retoned 2026-10-29;
before that their icons were still amber while their badges had moved.)

## The PDF

`proposals/scripts/render-pdfs.sh` (and the `pdf.yml` workflow) takes the family as variables and adds:

```css
h1 { color: #DEEP }
h2 { color: #DEEP; border-bottom: 2px solid #PRIMARY; padding-bottom: 4px }
h3, h4 { color: #MID }
a  { color: #ACCENT }                                   /* ACCENT defaults to PRIMARY */
blockquote { border-left: 4px solid #ACCENT; background: #TINT; padding: 6px 14px; margin-left: 0 }
th { background: #TINT; color: #DEEP }
details > summary { font-weight: 600; color: #MID }
hr { border: 0; border-top: 1px solid #PRIMARY; opacity: .45 }
```

`TONE=rainbow sh proposals/scripts/render-pdfs.sh` renders David's family: the H1 is a six-hue gradient, the H2s
cycle red, orange, yellow, green, blue, violet in order, rules are a gradient, and links are the blue. Badges for a
rainbow proposal take the six hues in order (number red, status orange, date yellow, "For" stays the shared slate `64748b`).
On the GitHub page, which strips colour from Markdown, a rainbow page is made by `python3 scripts/rainbow-heading.py --page <README>` in THEF's `proposals`: each H1 and H2 becomes an SVG of its words in the six hues (text kept in `<title>` and `alt`, anchor kept by hand, the same image drawn in the PDF), each `---` a rainbow divider, with `make-banner.py --family rainbow` for the banner.

Run `TONE_PRIMARY=5b2bb5 TONE_DEEP=3b1f6e TONE_MID=7c3aed TONE_TINT=ede9fe sh proposals/scripts/render-pdfs.sh` to
render in another family, or set the defaults at the top of the script once per repo. Maroon, which is what
`scripts/render-walkthrough-pdfs.sh` wears by default: `TONE_PRIMARY=800020 TONE_DEEP=1a1a2e TONE_MID=5c1a2b TONE_TINT=fbeef1 TONE_ACCENT=0f3460`.

## Decks (Marp)

`proposals/decks/*.marp.md` follow the same family: title slide and H1 in the primary on a dark ground, H2 in a
lighter primary, accents in the mid, and `section h1 { … !important }` so the default theme does not win. Render
with node on PATH and `CHROME_PATH` set, or Marp hangs (`walkthroughs/MARKDOWN-BESIDE-PDF.md`).

## Child folders

Every proposals repo carries one child folder per site or project repo it serves (`theholyearthfoundation/proposals/bushido-code/`, `…/iamoneself-retreats/`, `…/david-amaringo/`), empty but for a `.gitkeep` until a proposal belongs to that repo alone. Org-wide proposals stay at the root. The renderer walks both levels and writes `pdf/<child>/NNN-name.pdf`; a nested page links its icons as `../../assets/icons/`.

## Adding an organisation

Pick a family no neighbour uses (the table is the register), add the row here with its four shades, set the defaults
in that repo's render script, retone its icons, and use the badge recipe above in its `_template/README.md`.

# PUBLIC-ALLOWLIST-ATTESTED.txt — files a person opened and read before they travel to the public twin
#
# The public-lane tripwire (scripts/scan-public-lane.sh) reads every file it can. When it cannot (a scan or an
# image-only PDF, a picture outside assets/ or icons/, a .docx with a picture in it, any other binary), or when it
# finds a sensitive shape (an identity number, an address, a labelled account number, a personal-matter word), it
# refuses the file. An officer may then open the file, read every page, and add one line here:
#
#   path | officer | YYYY-MM-DD | opened and read
#   path | officer | YYYY-MM-DD | opened and read | sha256:<fingerprint the tripwire printed>
#
# The fingerprint is optional and recommended: with it, the attestation ends the moment the file changes, and the
# next sync asks for a fresh reading. Without it, the officer re-reads by habit.
#
# An attestation never opens these, whatever this file says:
#   - a credential or a pointer into agent notes found in any readable text
#   - entity/ tax/ filings/ counsel/ (the legal lanes)
#   - keys, wallets, environment files, agent-note folders, symbolic links, files over 15 MB
#
# The file itself travels nowhere unless PUBLIC-ALLOWLIST.txt lists it; adding a line is an officer's decision,
# made by pull request like the allowlist. Paths are the same as in PUBLIC-ALLOWLIST.txt (relative to this
# repository's root), one file per line, never a folder.
#
# Nothing is attested yet.
